## Matching blocklist entries

Omit `transaction_type` to look up both payment and payout entries. Set it to
`payment` or `payout` to restrict the lookup to that namespace. Empty or
unsupported explicit selectors are rejected.

The lookup remains scoped to the resolved business profile and merchant-wide
entries with no profile. Entries belonging to other profiles or merchants are
not returned. `X-Profile-Id` and default-profile resolution work as before.

`blocked` is true when `transaction_types` contains at least one matching namespace.
An unblocked value returns `blocked: false` and `transaction_types: []`.
Each transaction type appears once; data kinds and profile IDs are not returned.
Legacy NULL transaction namespaces are reported as payment.

```json
{
  "data": "blmg_shared",
  "blocked": true,
  "transaction_types": ["payment", "payout"]
}
```

Multiple matching rows in the same transaction namespace do not duplicate its name.
Transaction-type ordering is not significant.
