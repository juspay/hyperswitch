openapi: post /blocklist/batch
---

The CSV header is `type,data,metadata,transaction_type`. With no query selector,
set the last field to `payment` or `payout` per row; a single upload can contain
both blocklists. Older files without the column, or rows with an empty selection,
default to payment entries.

Use `POST /blocklist/batch?transaction_type=payment` or
`POST /blocklist/batch?transaction_type=payout` to override every valid row,
including conflicting row selections and older files. The selector is a query
parameter; the multipart request still contains only the `file` field.
Empty or unsupported query selections are rejected. Unsupported CSV selections
are rejected even when a valid query override is supplied.

The original CSV is preserved unchanged; worker chunks contain the effective
transaction type.
