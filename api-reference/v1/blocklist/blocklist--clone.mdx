---
openapi: post /blocklist/clone
---

Set the optional `transaction_type` field in the JSON request body to `payment`
or `payout` to clone only that namespace. Omission clones both payment and payout
entries. The selection is retained across retries and applies to every target
profile.

```json
{
  "target_profile_ids": ["pro_target_one", "pro_target_two"],
  "transaction_type": "payout"
}
```

Cloning preserves each entry's `transaction_type`; legacy NULL transaction types
are copied as payment entries. An entry already present in the same target
blocklist is skipped; an identical value in the other blocklist does not prevent
cloning. The response shape and job-status polling endpoint are unchanged.
