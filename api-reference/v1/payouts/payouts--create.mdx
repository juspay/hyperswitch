## External-vault card payouts

<Note>
  External-vault card payouts are not available in this release.
</Note>

Use a card saved during a payment. Provide a unique `payout_id`, the saved
`payout_method_id`, and the card owner's `customer_id` or `customer.id`.

Set `confirm=true`, `auto_fulfill=true`, `payout_type=card`, and `recurring=false`.
These values apply when omitted. Send the request from your server; no separate
confirmation call is required. Do not send card details, vault tokens, or vault
credentials.

## Retry handling

After a timeout, retrieve the payout using its `payout_id` before submitting
another request. Do not create a new payout ID to retry the same payout.

Creating a payout with an existing `payout_id` returns a duplicate-payout error.
Use `merchant_order_reference_id` for reconciliation, not retry protection.
