# Router

Main crate of the project.

## File upload request limit

`POST /files` accepts a complete multipart request of at most 11 MiB, including
multipart headers, boundaries, and all fields. The router counts bytes as the
body is read and returns HTTP 413 when the cap is exceeded, before multipart
parsing or authentication. This also applies to chunked requests without
`Content-Length`.

The cap leaves room for the largest supported file (Adyen's 10 MB images) and
multipart metadata. Connector-specific file size and MIME-type validation still
applies after authentication. JSON and typed multipart-form limits are separate.
